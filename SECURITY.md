# Seguridad y privacidad

Este repositorio usa exclusivamente datos sintéticos. No versione datos personales,
exports de producción, credenciales, tokens, claves, hosts privados ni identificadores
reales de recursos o clientes.

Los notebooks se autentican con la identidad del propio notebook y la configuración
de cada participante se guarda en su carpeta personal (`.z2h/config.json`), nunca en
el repositorio. No agregue al repositorio IDs de warehouse, nombres de catálogo reales,
hosts ni capturas que muestren identificadores del workspace.
